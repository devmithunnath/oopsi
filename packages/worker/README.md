# `@oopsi/worker`

Cloudflare Worker engine for [Oopsi](https://github.com/devmithunnath/oopsi) — D1 SQLite tickets & threads, private XSS-sandboxed R2 attachments, hashed-IP rate limiting, built-in `/admin` inbox UI, and pluggable adapters.

See the [root README](../../README.md) and [Self-Hosting Guide](../../docs/self-hosting.md).
